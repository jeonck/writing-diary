## 오늘의 문장

> let’s pick this up on Monday

## 일기 (Diary)

We had a long team meeting this afternoon that ran out of time. There were still a few things left to discuss, so my manager said, "Let's pick this up on Monday." I was actually relieved because I was starting to lose focus. The weekend feels like a good reset before we dive back in. I'm going to jot down some notes tonight so I don't forget where we left off.

> 오늘 오후에 팀 회의가 길어졌는데 시간이 부족했다. 아직 논의할 게 남아 있어서 팀장님이 "이건 월요일에 이어서 하죠"라고 했다. 사실 집중력이 떨어지던 참이라 솔직히 다행이었다. 주말이 지나면 다시 기운을 충전하고 돌아올 수 있을 것 같다. 오늘 밤에 어디까지 했는지 메모해 둬야겠다.

## 응용 문장 (Applied Sentences)

1. **We're out of time today — let's pick this up tomorrow morning.**
   오늘은 시간이 다 됐으니 내일 아침에 이어서 하자.
2. **The project ran long, so we decided to pick it up after the holiday.**
   프로젝트가 길어져서 휴일 이후에 다시 이어가기로 했다.
